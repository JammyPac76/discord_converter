# discord_converter
A script used for compressing videos (specifically made for Discord's pesky filesize limit)
# Requirements
You need to have the following:
- [FFmpeg](https://github.com/ffmpeg/ffmpeg) - The main powerhouse of this script, used for compression.
#### Python modules
- [opencv-python](https://pypi.org/project/opencv-python/) - Used to get video data
#### Optionally
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - For downloading videos if the `--download` argument is `True`.
